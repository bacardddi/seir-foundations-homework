I am the spotter for = Richie Bias
5 things I learned that I shared with them:
1. Check your prompt - I learned to check my prompt before Step 0. If it
   ends in # and says root, I should type exit to go back to ec2-user.
   I did all my runs as root by accident.
2. Run the ID line every time - I learned to run the ID line (whoami,
   date, ec2-metadata -i, uptime -s) before every screenshot. I forgot
   it on my return-code screenshots and had to retake them.
3. Plan your lab runs - I learned you only get 3 lab-run screenshots
   per day, so you have to spread the 7 runs across at least 3 days.
   If you leave an instance running past midnight, it counts as the
   next day.
4. Return code 12 means wrong folder - I learned that return code 12
   with FILE-STATUS=35 means I ran the COBOL program from the wrong
   folder. Running cd /opt/balerica-bank first fixes it.
5. Rejected payments are saved - I learned that rejected payments still
   get written to payments.dat, but the balance doesn't change. I also
   learned to use a new TXN ID each time so I don't create duplicates.
